ER-диаграмма базы данных

📊 Модель данных

Схема базы данных: Хирурги, Пациенты, Операции, Лекарства

🗂️ Сущности базы данных

👨‍⚕️ Surgeon (Хирург)

  • PK surgeon_id — уникальный идентификатор
  • first_name — имя
  • last_name — фамилия
  • specialization — специализация
  • license_number — номер лицензии

👤 Patient (Пациент)

  • PK patient_id — уникальный идентификатор
  • first_name — имя
  • last_name — фамилия
  • date_of_birth — дата рождения
  • blood_type — группа крови
  • insurance_policy — страховой полис

🔪 Surgery (Операция)

  • PK surgery_id — уникальный идентификатор
  • FK surgeon_id — ссылка на хирурга
  • FK patient_id — ссылка на пациента
  • surgery_date — дата и время операции
  • diagnosis — диагноз
  • status — статус

💊 Medicine (Лекарство)

  • PK medicine_id — уникальный идентификатор
  • trade_name — торговое название
  • active_substance — действующее вещество
  • dosage_form — форма выпуска

🔗 Surgery_Medicine_Link (Назначения)

  • PK link_id — уникальный идентификатор
  • FK surgery_id — ссылка на операцию
  • FK medicine_id — ссылка на лекарство
  • dosage — дозировка
  • frequency — частота приёма

🧠 Как работает нейронная сеть?

В отличие от линейной регрессии (простая формула) и дерева решений (правила "если-то"), нейросеть использует множество связанных нейронов, которые совместно принимают решение.

📊 Архитектура нашей сети:

  • Входной слой: 4 признака (gender, lunch, test_prep, reading)
  • Скрытый слой: 2 нейрона с функцией активации sigmoid
  • Выходной слой: 1 нейрон (прогноз math score)

🔄 Процесс обучения:

  1. Данные проходят через сеть (прямой проход)
  2. Вычисляется ошибка между прогнозом и фактом
  3. Ошибка распространяется назад (backward pass)
  4. Веса корректируются для уменьшения ошибки
  5. Повторяем 1000 раз (эпох)
